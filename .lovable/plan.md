# Roman Hrydin Portfolio

## Goal
Build a polished, recruiter-friendly single-page portfolio using the supplied portrait, certificates, project screenshots, and English CV. The project will use the existing supported TanStack Start application structure while matching the requested React, TypeScript, semantic HTML, responsive behavior, and production quality.

## Build
- Create an original warm off-white, graphite, and golden-yellow visual system with strong sans-serif typography.
- Add a sticky accessible header, mobile menu, smooth in-page navigation, hero, about, technology stack, four projects, education and certificates, professional background, CV call-to-action, contact area, and footer.
- Store repeated project, technology, education, and contact content in typed data modules and render it through reusable components.
- Use the supplied portrait, actual project screenshots, GoIT certificate, EPAM diploma, and English CV through the project asset system.
- Add an accessible certificate viewer, safe external links, keyboard focus states, reduced-motion support, and mobile-first layouts without horizontal overflow.
- Add route-specific search and social metadata and an original RH favicon.

## Content safeguards
- Include exactly the four specified projects and no invented repository links or features.
- Use only the supplied English CV for both download buttons.
- Keep experience, education, language level, dates, contact details, and project claims factual.

## Verification
- Check mobile and desktop layouts, navigation, menu, certificate viewer, CV link, project links, contact links, focus behavior, and overflow.
- Confirm the preview builds cleanly and address any TypeScript or runtime errors reported by the project.
